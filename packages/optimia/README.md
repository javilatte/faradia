# optimia is now Faradia

optimia has a new name: **Faradia**. Same app, same data: your settings, agents and repos move over
on their own the first time you run it.

```sh
npm i -g faradia
faradia
```

This package (`@javilatte/optimia`) installs Faradia and runs it with the old `optimia` command. It
will keep getting updates for a few more months; after that, only `faradia` will.
